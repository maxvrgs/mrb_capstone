# Marketplace

## Descripción

Plataforma de comercio electrónico orientada al mercado chileno.

El sistema combina:

1. Marketplace tradicional
2. Tiendas personalizadas
3. Subastas en tiempo real
4. Sistema de pagos con custodia
5. Verificación de identidad
6. Validación física mediante OTP

## Usuarios

### Compradores

Pueden:

- Buscar productos
- Comprar productos
- Participar en subastas
- Realizar seguimiento de pedidos

### Vendedores

Pueden:

- Crear una tienda
- Publicar productos
- Crear subastas
- Administrar ventas
- Recibir pagos

### Administradores

Pueden:

- Gestionar usuarios
- Gestionar vendedores
- Supervisar transacciones
- Resolver disputas
- Administrar la plataforma
